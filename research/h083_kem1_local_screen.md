## Conservative ordinary-KEM valuation
Using the ordinary KEM-1 reference content:

`0.002 g Au * 175 + 0.002 g Pd * 58 = 0.466 AZN/unit`

versus seller ask:

`2.00 AZN/unit`.

Even before buyer discount, transport, sorting, minimum-lot rules or recovery costs, theoretical contained-metal value is only **23.3% of ask**.

For a 250-unit box:
- acquisition cost = **500 AZN**;
- ordinary-reference contained-metal basis ≈ **116.5 AZN**;
- gross deficit ≈ **383.5 AZN** before execution costs.

## Ambiguity control
The higher `Контакт КЭМ-1` reference (~0.0147452 g Au) would imply a very different value, but this cannot be safely mapped to the listing from text alone. The listing describes a glass reed contact / qerkon and an OCR-like `зА` marking, not a verified catalog identity tied to the high-content reference.

Strict project rules therefore prohibit using the favorable table row without exact identity proof.

## Result
At the current **2 AZN/unit** ask, the ordinary KEM-1 interpretation is decisively uneconomic. The listing is **not a SUCCESS candidate** and should not be purchased for precious-metal arbitrage without a model-specific binding buyer quote that independently exceeds 2 AZN + all costs.

This packet is still useful because it establishes a fast filter for future Soviet-component searches: low-content KEM reed switches should be rejected even when asks look small.
