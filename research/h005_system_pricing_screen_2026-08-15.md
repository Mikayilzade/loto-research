# H005 — system-ticket pricing and deterministic bundle discounts

Updated: 2026-08-15
Status: **no guaranteed-profit nonlinear pricing edge found in screened current examples; one real deterministic discount found but guarantee-rejected**

## Goal
Search for current pricing structures that genuinely evade the additive-portfolio theorem: system tickets cheaper than their constituent combinations, fixed bundle discounts, fractional/syndicate pricing, or other deterministic acquisition discounts.

A discount is economically real, but for terminal `SUCCESS` it must be large enough that the portfolio's minimum cash payout exceeds the discounted acquisition cost after fees/tax.

## 1. Australia — Oz Lotto System 8 is exactly linear
Current Oz Lotteries system page states that a System 8 covers all eight 7-number combinations generated from eight selected numbers.

Current displayed prices on the same page:
- 4 standard games: AUD 6.60;
- 10 standard games: AUD 16.50;
- 18 standard games: AUD 29.70;
- System 8 = 8 games: AUD 13.20.

Thus the displayed unit price is exactly AUD 1.65 per constituent game in both standard and System-8 packaging:

`13.20 / 8 = 1.65`

`6.60 / 4 = 1.65`

No package discount exists in this screened system example. The system changes coverage/convenience only and therefore remains inside the H012a linear theorem.

Source checked 2026-08-15:
- https://www.ozlotteries.com/oz-lotto/systems
- https://support.ozlotteries.com/hc/en-us/articles/360000265076-How-do-System-tickets-work

Status: **REJECTED as nonlinear-pricing edge for this current example.**

## 3. Poland fractional coupons / syndicate split do not reduce acquisition cost
The same official page exposes `kupony cząstkowe` (fractional coupons): one Lotto/system ticket can be split among multiple participants, each receiving a fractional claim on winnings.

Crucial rule: the **entire underlying ticket must first be paid in full** before fractional coupons are issued. Each fraction then receives the same fraction of the prize. Tax is calculated on the full prize attached to the underlying bet before division.

Therefore fractionalization changes capital sharing between participants, not the total ticket economics. It cannot create a portfolio-level guaranteed-profit arbitrage.

Source: same official LOTTO Poland page, section on `kupony cząstkowe`.

Status: **REJECTED as pricing arbitrage.**

## 4. NEW — current deterministic bundle discount exists on LOTTO Poland
A current official lotto.pl site-wide purchase banner (freshly indexed in August 2026) displays:
- `Chybił trafił` (Quick Pick);
- 3 bets;
- 1 draw;
- normal price PLN 13.00;
- `ZAGRAJ ZA 12,00 ZŁ` (play for PLN 12.00).

This is a genuine deterministic acquisition-price nonlinearity of PLN 1 versus the displayed reference price, approximately **7.69% discount** on the 13-PLN reference bundle.

Fresh official pages carrying the banner include:
- https://www.lotto.pl/
- https://www.lotto.pl/winto/

### Guarantee test
The bundle consists of random lottery bets and still admits a legal branch in which every purchased line returns zero cash. Therefore its minimum lottery payout is:

`F = 0`.

Discounted cost:

`C = 12 PLN`.

Even if the entire 1-PLN discount is treated as deterministic subsidy, terminal minimum net is at most:

`F - C = -12 PLN` relative to the paid cash outlay,

or equivalently the discount improves the reference economics by only PLN 1 but does not create a positive floor.

A strict guaranteed-profit criterion requires `F > C`; here `0 > 12` is false.

Thus the discount is **real and economically useful for EV**, but **REJECTED as a guaranteed-profit strategy**.

## 5. General result from this packet
A deterministic percentage/bundle discount `d` can only produce terminal guaranteed profit if the undiscounted portfolio already has a minimum cash return ratio above the discounted cost ratio:

`F / C_original > 1 - d`.

For a portfolio with a legal zero-return branch (`F=0`), **no positive but sub-100% acquisition discount can create guaranteed profit**.

Therefore future bundle/system-discount searches should be filtered immediately:
1. if portfolio floor is zero, only a 100%+ cash-equivalent subsidy can satisfy the strict guarantee criterion;
2. if portfolio floor is positive, compare the verified discount directly with the known guaranteed deficit;
3. do not spend optimization effort on ordinary systems whose price is exactly constituent-linear.

## Current conclusion
This packet closes three common H005 mechanisms for the screened examples:
- exact constituent-linear system pricing: no edge;
- fractional/syndicate splitting with full-ticket payment: no edge;
- modest deterministic bundle discount on a portfolio with zero-return outcomes: improves EV but cannot guarantee profit.

No `SUCCESS` found. H005 remains open only for genuinely large discounts/refunds, nonzero guaranteed payout floors, or nonlinear pool/payout rules capable of making `minimum cash payout > net acquisition cost`.
