## H336 — WinWink live Charizard Every-Ticket-Wins postal bundle

Checked 2026-08-28.

Mechanism tested:
- live UK free-postal route;
- operator-specific postal bundle formula `floor(second-class stamp / ticket price)` with minimum one ticket;
- every identifier carries a published prize;
- instant-win positions cryptographically pre-committed before sales;
- explicit cash alternatives permit strict withdrawable-cash evaluation.

Exact result:
- 7,274 / 7,274 prize identifiers reconciled;
- total all-cash-alternative liability £9,159.10;
- £2.50 ticket price and £0.91 second-class benchmark => one ticket per postal submission;
- 3,215 identifiers have only £0.08 cash alternative;
- legal accepted-entry worst case = **-£0.83** before material/labour costs;
- arithmetic inconclusive = 0;
- strict guarantee = FAIL.

Independent execution blocker: current terms disclaim lost/delayed/non-delivered post and reject tracked/signed/premium methods for free entry.

Do not repeat this exact game unless prize structure or postal allocation changes materially. Reuse the postal-bundle theorem on cheap WinWink games where one postcard allocates `k >= 2` tickets and test the worst k-identifier cash-support sum, not EV.
