# H292 — current RaffleTix finite sponsored-raffle takeover screen

Checked: 2026-08-26
Status: **CLOSED for the five screened current finite pools; NO SUCCESS**

## Why this class matters
A hard-capped raffle with no entry limit per participant is structurally attractive for strict-guarantee research. If one participant could acquire every issued identifier, every winning ticket would be theirs and random selection would cease to matter. Sponsored prizes can in principle create winner-facing value above ticket revenue, so this class is worth screening directly.

H292 intentionally uses a stronger-than-real model: assume an eligible player can buy every identifier before anyone else and can always use the cheapest published bundle price. If the complete advertised prize pool is still below that impossible-perfect acquisition cost, no execution detail can rescue a full-buyout guarantee.

## Structural conclusion
All five have a published hard ticket cap and no per-player maximum in the checked terms/pages, so they pass the *finite monopolizable identifier* structural screen much better than open lottery raffles. However, none passes the economics screen. The best possible full-buyout gross among them is only 77.119% of acquisition cost.

This is stronger than rejecting a practical takeover on availability grounds: H292 grants complete ownership from inception. Therefore partial availability, competing buyers, card limits, residency constraints, valuation haircut, taxes, delivery costs, or non-cash prize liquidity can only make the real result worse.

## Reopen rule
Do not repeat these five under unchanged ticket caps/prices/prize pools. Reopen only if a deterministic discount/subsidy materially lowers full acquisition cost, the prize pool is increased, or a new finite raffle has advertised prize liabilities exceeding the cheapest full-ticket acquisition cost.
