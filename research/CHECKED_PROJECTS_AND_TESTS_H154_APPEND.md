# H154 audit append — KenoGO Jackpot hidden-state cover

Updated: 2026-08-21

| Project / mechanism | Test variant | Result | Status / evidence |
|---|---|---|---|
| **H154 KenoGO Jackpot 1-Spot complete cover** | buy all 80 one-number Jackpot tickets at AUD 2 each | cost AUD 160; exactly 20 winners; Regular gross AUD 60 = **37.5%**, Minor gross AUD 200 = **125%**, Major gross AUD 500 = **312.5%** | **CONDITIONAL PAYTABLE OVERLAY VALIDATED**; `research/h154_kenogo_jackpot_hidden_state_cover.md` |
| **H154 pre-announced Minor/Major hypothesis** | condition purchase of full cover only on Minor/Major draw | would yield nominal +AUD 40 / +AUD 340 before cap/tax if state were known while betting remained open | **REJECTED by regulatory timing**: Victoria Government Gazette says Top Prize level is determined at conclusion of game from sum of drawn 20 numbers, while entries close before draw |
| **H154 unconditional Jackpot cover** | buy all 80 before unknown state resolves | lawful Regular state returns only AUD 60 on AUD 160 | **REJECTED strict guarantee**, all-state floor **37.5%** |
| **H154 KenoGO Classic 1-Spot cover** | buy all 80 at AUD 1, fixed AUD 3 1-Spot prize | AUD 80 cost, exactly 20 winners, AUD 60 gross = **75%** | benchmark validated; subsidy hurdle **>25% of face spend** or >33.333% bonus relative to external cash depending funding convention |
| **H154 100% deposit-match + Classic cover** | historical/targeted match supplies AUD 40 bonus on AUD 40 external cash, funding AUD 80 face | conditional AUD 60 winnings vs AUD 40 external cash = **+AUD 20** | **PROMISING STRUCTURE ONLY / NOT CURRENT SUCCESS**: no public universally claimable Aug-2026 100% offer found; current T&C make offers eligibility-specific and permit bonus-abuse/stake-limit discretion |
| **H154 payout-cap/sharing gate** | test whether state-conditioned cover survives other top-prize winners | current FAQ says Tier One payouts are prorated if draw-wide maximum payout is exceeded | **SECONDARY GUARANTEE BLOCKER**; exact cap/external exposure must be bounded for any future state-observable variant |

Conclusion: the first raw Keno paytable states above 100% deterministic cover were found, but they are deliberately hidden until after same-draw entry closes. Reopen this exact mechanism only if a lottery exposes a boosted top-prize/paytable state before sales cutoff, or if KenoGO changes its regulatory/game timing.
