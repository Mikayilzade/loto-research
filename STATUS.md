# H099 — Azerbaijan cultural export valuation / mandatory state acquisition: COMPLETED THIS PACKET
Files:
- `research/h099_azerbaijan_cultural_export_mandatory_buyout.md`
- `research/CHECKED_PROJECTS_AND_TESTS_H099_APPEND.md`

Current consolidated Cabinet Decision No. 294 was tested as a possible buy-below-official-value / redeem-to-state arbitrage.

Validated mechanics:
1. permanent-export application is **owner-gated** and requires the owner's acquisition basis;
2. Ministry expertise must state the cultural property's **market value**;
3. ordinary state acquisition under Rule 12.1 is only a **right to purchase**, so strict guarantee fails on a lawful no-purchase branch;
4. Rule 12.2 is materially stronger: when a physical person leaves Azerbaijan to live permanently abroad, the Ministry **must pay** that person the amount in the value document as a one-off payment.

This is a real mandatory-payout subclass. However, it does not create a reproducible pre-acquisition arbitrage for an ordinary buyer because official valuation occurs after the applicant already owns/presents the object. A seller's emigrant-specific entitlement does not automatically transfer to a later ordinary buyer.

Strict execution gate:
`locked mandatory payout to post-purchase holder - fixed acquisition price - all costs > 0`, with the entitlement surviving transfer and Ministry/custodian confirmation before payment.

Status: **MANDATORY-PAYOUT SUBCLASS VALIDATED / PRE-ACQUISITION ARBITRAGE REJECTED / NOT SUCCESS**.
