# H100 — prefunded notary-deposit claim assignment: COMPLETED THIS PACKET
Files:
- `research/h100_prefunded_notary_deposit_claim_assignment.md`
- `research/CHECKED_PROJECTS_AND_TESTS_H100_APPEND.md`

A materially stronger form of H093 has been validated in principle under Azerbaijan law.

Key mechanics:
1. Civil Code Arts. 193–199 broadly allow transfer of non-personal claims; the assignee generally steps into the creditor's existing position.
2. Under Notariat Arts. 74–75, a debtor may place money/securities with a notary for the creditor; the notary pays the creditor on demand.
3. Return of the deposited money to the debtor is constrained: written creditor consent or a court decision is required.
4. Therefore an **already-funded notary-deposit claim** can, in principle, create a deterministic arbitrage if bought below the locked distributable amount and the assignee is recognized before seller payment becomes irreversible.

Strict execution theorem:
`locked notary deposit - surviving defenses/deductions - acquisition price - all transfer/tax/bank costs > 0`.

Required atomic workflow:
`verify deposit -> verify assignability/no defenses -> execute assignment -> notify/register assignee -> notary confirms assignee payout -> release seller payment`.

Current blockers:
- no concrete below-face already-funded notary-deposit claim was found;
- no public marketplace for this claim class was found;
- exact notarial classification/fees and assignee-payment workflow must be confirmed on a real case;
- Civil Code Art. 199 means pre-existing defenses can survive assignment;
- retention/limitation deadlines must be checked per candidate.
