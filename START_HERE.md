# START HERE

Это основной файл входа в проект **loto-research**.

## Цель
Системно исследовать лотереи и сходные игры с денежным ожиданием: правила, стоимость участия, призовые структуры, исторические тиражи, математическое ожидание, дисперсию, риск, налоги/комиссии, промо-механики и потенциальные рыночные/операционные аномалии.

Цель исследования — найти и доказать воспроизводимые условия положительного математического ожидания, если они существуют, либо строго показать, почему конкретная идея не работает.

## Как продолжать работу в новом чате
1. Прочитать `START_HERE.md`.
2. Прочитать `PROJECT_RULES.md`.
3. Прочитать `STATUS.md`.
4. Прочитать `RESEARCH_PLAN.md`.
5. Проверить фактическое состояние ветки `research-work` в GitHub.
6. Продолжать с текущего незавершённого этапа, не восстанавливая состояние по памяти.

## Рабочая ветка
`research-work`

## Основной принцип
Никакая идея не считается рабочей без численной модели, воспроизводимого теста и проверки на независимом периоде данных.
